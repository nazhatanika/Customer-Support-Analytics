# Customer Support Analytics

A full-stack customer support ticketing system — built to generate, store,
and analyze 25,000+ support tickets.

**Stack:** PostgreSQL · Redis · FastAPI · React · Power BI · ML

## Status
- [x] Phase 1 — project skeleton (API + web app + database + cache all running)
- [ ] Phase 2 — database schema + synthetic data generator
- [ ] Phase 3 — full REST API
- [ ] Phase 4 — frontend application
- [ ] Phase 5 — analytics (SQL + Power BI dashboards)
- [ ] Phase 6 — machine learning (7-day recontact prediction)
